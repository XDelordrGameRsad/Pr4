# Практическая работа №4 — Наследование, интерфейсы и полиморфизм

Вариант: А — Воин. Язык: Java, JDK 21. Maven не используется.

## Сборка и запуск

```powershell
javac -encoding UTF-8 -d out (Get-ChildItem -Recurse src -Filter *.java).FullName
java -cp out kz.javaworkshop.Main
```

В `Main` реализованы контрольный проход шага 6 и дополнительные сценарии шага 7.
Для вариантов Б и В замените параметры Алии в `Main` в соответствии с таблицей задания.
